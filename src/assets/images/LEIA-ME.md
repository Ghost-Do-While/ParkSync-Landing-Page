Formatos aceitos: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`. Use uma imagem quadrada
(400×400 px ou maior) com o rosto centralizado.

Se a foto não existir aqui, o site usa a foto de perfil do GitHub. Se o GitHub também
falhar (sem internet, por exemplo), aparecem as iniciais.

Também dá para apontar um arquivo com outro nome pelo campo `photo` em
`src/data/content.js`, por exemplo `photo: 'emily-maquete.png'`.
